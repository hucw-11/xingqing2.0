- 克隆上游（只读，不运行其构建脚本）：

```bash
git clone --depth 1 https://github.com/qiqqqqq517/shangkeschedule.git
git clone --depth 1 https://github.com/Demizo/Daily_You.git
```

- 本地无 JDK/Android SDK/Gradle，构建交给 GitHub Actions：
  - Android：`./gradlew :shared:jvmTest :androidApp:lintDebug :androidApp:assembleDebug`
  - Windows：`.\gradlew.bat :shared:jvmTest :desktopApp:createDistributable`
- 本机签名（需已下载未签名 APK 与 apksigner.jar）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sign-apk.ps1 -UnsignedApk <APK> -ApkSignerJar <apksigner.jar>
```
