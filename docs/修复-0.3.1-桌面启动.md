# 0.3.1 桌面启动修复

用户反馈：0.3.0 Windows启动后显示 `KoinApplication has not been started`。

## 根因与修改

- 上游桌面Main直接调用App，未初始化全局Koin；App第一行就通过Koin获取SettingsViewModel。安卓有Application初始化，所以该缺陷主要发生在桌面入口。
- 新增DesktopModule/DesktopAppConfig，在创建Compose窗口之前启动Koin，退出时关闭容器。
- 补齐桌面专用的AppVersionCode、AppVersionName绑定，构建时从Android版本配置生成，避免手写两套版本号。
- 新增无窗口回归：强制java.awt.headless=true，以build目录隔离资料，使用真实容器获取设置与日程ViewModel，并等待设置读取和启动门控就绪。
- CI在生成Windows包前执行desktopApp:test。此测试不启动GUI、不操作用户桌面、不读取真实APPDATA。
- 新包版本0.3.1 / code4；数据目录与0.3.0相同，不清除用户数据。
