# 微信提醒费用与调度方案（P0 草案）

调查日期：2026-11-16
状态：方案草案，价格与额度以购买时官方页面为准；P6 前需用真实账号实测。

## 1. 需求与发送量估算

提醒类型：课程、日程/待办、写日记。按个人使用估算：

- 上课日：6–12 条/天（课前提醒 + 日程 + 待办 + 写日记）。
- 休息日：2–5 条/天。
- 峰值按 20 条/天、600 条/月估算，留 5 倍余量。

## 2. 推送通道：Server酱

官方文档与订阅页（2026-11-16 查询）：

| 项 | 免费会员 | 付费会员 |
|---|---|---|
| 每日额度 | 5 条/天 | 1000 条/天 |
| 频率 | 50 条/分钟 | 50 条/分钟 |
| 消息保留 | 1 天 | 3 天 |
| 价格 | 0 | 8 元/1 个月；39 元/12 个月（约 3.25 元/月）；180 元/60 个月（约 3 元/月） |

- 免费额度对上课日可能不够，建议付费年费。
- 官方写明不支持自动续费、不支持退款；购买前再次核对。
- 免费/付费额度与价格可能调整，以上仅为本轮查询结果。

## 3. 调度端候选

| 方案 | 免费/费用 | 能力与限制 | 风险 |
|---|---|---|---|
| Cloudflare Workers + Cron（免费层） | 0 元 | 每账号 5 个 cron；最小 1 分钟粒度；单次 cron CPU 10ms、墙钟 15 分钟；10 万请求/天；**无自动重试** | 国内可达性、10ms CPU、无重试、KV/D1 免费额度需核实 |
| 阿里云函数计算 FC + 定时触发器 | 首次开通约 3 个月、每月 15 万 CU 免费（官方产品页）；之后按 CU 计费，2026-03-16 起单函数小时级最低消费约 0.01 元/小时 | 国内网络稳定；cron/间隔/指定时间触发器；无请求不计费 | 需要阿里云账号与实名；小时级最低消费对高频任务不友好；免费额度说法需以控制台为准 |
| 小型 VPS | 约 10–30 元/月（未核实具体供应商） | 完全可控、可观测、可重试 | 固定月费、需要运维与安全更新 |

粗略月成本：

- Cloudflare Workers + Server酱 年费：约 **3.25 元/月**（Server酱摊销），调度 0 元。
- 阿里云 FC + Server酱 年费：低频场景通常 **几元/月** + 3.25 元，需实际账单验证。
- VPS + Server酱 年费：约 **13–33 元/月**。

## 4. 推荐

**首选：Cloudflare Workers（免费层）+ Server酱 年费会员。**

- 月成本约 3.25 元，符合“少量费用”的预期。
- 用一个每分钟触发的 cron 拉取到期计划并发送；计划存 KV 或 D1，发送前检查版本与状态。
- 因为 Workers cron 无自动重试，必须自建幂等与重试状态机；错过触发时按“过期提醒策略”处理，不补发过时课前提醒。

**备选：阿里云函数计算 FC。**

- 如果实测发现 Cloudflare 在国内触发不稳定或 Server酱 API 连通性差，切到阿里云；代码逻辑保持平台无关。
- P6 前用真实账号各跑 2 天、每天 20 条测试消息，记录调度延迟、通道接受率、实际微信到达率。

## 5. 预算建议

- 常态上限：**≤ 5 元/月**（Server酱 年费摊销 + 免费调度）。
- 一次性测试成本：按实际购买，预计 ≤ 10 元。
- 若必须上 VPS，月度上限提高到 **≤ 30 元/月**，需要用户单独确认。

## 6. 购买/部署前必须核实

1. Server酱当前价格、每日额度、消息展示位置与频率限制。
2. 所选调度端到 Server酱 API 的网络连通性与延迟。
3. 微信实际到达情况（HTTP 成功不等于手机收到）。
4. Cloudflare KV/D1 免费额度是否够存计划与投递状态。
5. 阿里云 FC 的免费额度、最低消费与账单口径。
6. 失败重试、版本替换、取消指令、过期策略的真实行为。

## 7. 安全与最小化

- Server酱 SendKey 只存云端密钥/环境变量，不进仓库、不进日志、不进同步包。
- 客户端提交给云端的字段仅限：对象 ID、原始实例 ID、渠道、提前量、计划版本、最少标题/文案；**不提交日记正文**。
- 云端不需要解密全部日记；写日记提醒只发送“该写日记了”这类固定文案。
