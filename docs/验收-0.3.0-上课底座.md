本批目的：确认保留了用户喜欢的原版课程、日程与时间轴体验。新增日记、心情统计、AI、双向同步和微信提醒尚未接入，不能当作本批已完成内容。

## 安装与数据

- 安卓包名沿用 `com.hucw.xinqing2`，versionCode 3；使用既有固定证书签名后才交付。
- 心晴旧dev数据不清除，但本批没有迁移到上课的Room模型，新页面不会自动显示旧dev课程。
- 桌面完整解压交付zip后，手动运行 `Xinqing2.exe`。不要只把exe从压缩包里拖出来运行；它需要同目录的运行时和资源。
- 桌面数据单独存于 `%APPDATA%/Xinqing2/UpstreamBase`；手机与桌面此时尚未同步。
- 开发期间未启动桌面GUI或自动点击验证。下面步骤由用户自行完成。

## 建议5分钟测试

1. 打开应用，确认应用名“心晴 2.0”，默认进入日程页；观察月份展开/收起、日期切换和列表样式，确认与喜欢的“上课”体验一致。
2. 在“我的”设置学期、节次及一门课程。选择对应日期，确认课程出现在日程页。
3. 从日程页创建一个有时间的活动，再创建一个待办；确认与课程同屏，完成待办后状态正确。
4. 关闭再打开应用，确认课程、活动和待办完成状态保留。
5. 在课表导入导出入口选择已有格式文件，先检查预览，再确认导入。原版支持 .xlsx；二进制 .xls 按已确认范围提示另存为 .xlsx。
